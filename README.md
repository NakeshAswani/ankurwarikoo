# 🎤 Ankur Warikoo – Personal Brand Website Clone

A frontend clone of the Ankur Warikoo personal brand website built using HTML, CSS, and JavaScript, focused on layout accuracy and clean UI presentation.

## 🌐 Live Demo
https://ankurwarikoo-clone.vercel.app/

## 🧰 Tech Stack
- HTML
- CSS
- JavaScript

## ✨ Features
- Clean and minimal personal brand website layout
- Responsive design for different screen sizes
- Well-structured sections (Hero, About, Content, Contact)
- JavaScript-based UI interactions
- Modern and readable user interface

## 🧠 Project Overview
This project is a frontend clone of a personal brand website created to practice layout structuring, responsive design, and basic interactivity using JavaScript. The focus was on recreating a clean and professional personal website interface.

## 📥 Installation & Setup
1. Clone the repository  
    ```bash
    git clone https://github.com/NakeshAswani/ankurwarikoo.git
    ```
2. Navigate to the project directory
    ```bash
    cd ankurwarikoo
    ```
3. Open the project
    ```bash
    Open index.html in your browser
    ```
